Edit your website content

Sign in with your Google account to update papers, projects and CV details.

Firebase is not connected yet. Open assets/js/firebase-config.js, paste your Firebase web config and set enabled: true. See FIREBASE_SETUP_GUIDE.md.

You can still edit here and use Download JSON to update data/site-data.json by hand.

Papers

Change a status straight from the list. Counts on the website (e.g. "8 published or accepted") update by themselves.

Website text

Every text block of the website, section by section. Changes are kept in the editor; click Publish changes to make them live. Numbers like {{accepted}} or {{AcceptedWord}} are filled in automatically from the Papers list.

Projects

Choose where each project appears: on the website, in the CV (Selected or Additional), or both.

Recent updates

Shown in the "Recent Updates" section and in the "Latest" box at the top of the website, newest first.

CV details

Papers and projects come from their own tabs. Formatting inside CV text: **bold**, *italic*, [link text](https://...). Every list also has Edit as JSON if you prefer code.

Co-author links

Names written exactly like this in a paper's author list become Google Scholar links on the website.

All website data

Every section of the site (profile, education, skills, honors...). Edit carefully, then Apply.

Backups

A copy of the live content is saved before every publish. Restoring loads it into the editor; publish to make it live.
